Base model

N-ATLaS — Nigeria's sovereign multilingual LLM trained on 392M tokens across English, Hausa, Igbo and Yoruba. Developed by NCAIR / Awarri Technologies, built on Llama-3 8B.

Fine-tuning method

QLoRA (4-bit quantisation + Low-Rank Adaptation). Only 13.6 million of 8 billion parameters are trained. Runs on a single T4 GPU with no paid cloud infrastructure.

Training data

83 hand-crafted input/output pairs. Every citation verified against the official Federal Republic of Nigeria Gazette (Act No. 37, 2023). Zero hallucinated provisions used in training.

Benchmark result

Evaluated on 247 questions. Trained model correctly cited the relevant NDPA section 20.2% of the time. The uninstructed base model: 4.0%. The instructed base model: 7.3%.
